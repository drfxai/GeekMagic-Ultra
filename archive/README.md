Superseded DrFX artifacts, kept for reference. Nothing here is used by the
current build, and nothing here should be treated as documentation of how the
project works today.

| File | What it was | Superseded by |
|---|---|---|
| `DrFX-GodMode-Bridge-v1.zip` | the 1.x bridge, packaged for pasting into the Cloudflare dashboard | [`bridge/worker.js`](../bridge/worker.js) — deploy it with `bridge/deploy.sh` or straight from the dashboard |
| `godmode-screen-v1.png` | a photograph of the 1.x screen design | [`ui/screens-preview.html`](../ui/screens-preview.html) — every current screen at true size, in a browser |

Both predate the 2.0 redesign. The screenshot in particular shows the old
bordered-panel layout that [docs/DESIGN.md](../docs/DESIGN.md) exists to replace,
so do not use it as a reference for what the device looks like now.

Safe to delete if you would rather not carry the history.
