DRFX ULTRA OS

KEY GENERATOR · RUNS OFFLINE · NOTHING IS SENT ANYWHERE

1. Webhook key — TradingView uses this

Goes into Cloudflare as the secret WEBHOOK_KEY.

2. Device key — your SmallTV uses this

Goes into Cloudflare as the secret DEVICE_KEY, and into the device's Bridge tab.

3. Your worker name

Cloudflare prints this when you deploy. Type it here and the two addresses below fill themselves in.

4. TradingView webhook URL

Paste into the Webhook URL box of a TradingView alert.

5. Bridge URL for the device

Paste into Bridge URL on the device's settings page. No slash at the end.

Keep these private. Anyone with the webhook key can push fake signals to your screen; anyone with the device key can read them. They are not passwords you need to remember — save this page's output somewhere safe, or just come back and generate new ones, which instantly retires the old.

Never commit them. If you write them into a file, keep it out of Git. The repository ignores SECRETS.local.md for exactly this.
